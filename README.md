## 分支特色功能

图文并茂版：讲义正文与附录（幻灯片逐页转录）中的插图均直接取自官方幻灯片。

- **插图直接取自官方幻灯片**：讲义正文与附录中的插图均为官方幻灯片内嵌的原始图片，对照理解无需跳转；

- **按讲次组织、懒加载**：图片统一放在 `img/` 目录（`lect1-*.webp`、`lect2-*.webp`）随站点发布，并启用 `loading="lazy"`，不拖慢首屏加载。
