# 南京大学《生成式软件工程》（AI_Reader 分支）

**站点入口**：<https://wangchenglong-0712.github.io/Generative-Software-Engineering/AI_Reader/>

## 分支特色功能

提供 **AI 播客模块**（`podcast.html`，基于 Web Speech API 语音合成，纯本地运行）：

- **多音色朗读**：把每讲的核心观点整理成播客文稿，用不同音色讲给你听，可先「试听」再切换，切换立即生效；
- **波形动画与章节高亮**：播放时波形随声音律动，正文随播放进度实时高亮对应章节，边听边读；
- **断点续播**：自动记住上次播放位置、所选音色与语速，下次打开直接从断点继续；
- **倍速播放**：支持倍速调节，立即生效且不打断当前播放位置。

入口：首页顶部「♪ 播客」按钮，或直接访问 <https://wangchenglong-0712.github.io/Generative-Software-Engineering/AI_Reader/podcast.html>
