## 关于本课程

《生成式软件工程》（GenSE）是南京大学 2026 秋季学期开设的一门**实验性课程**，主讲教师为**蒋炎岩**，副标题是「AI 时代还有用的软件工程智慧」。

它不打算教你某个新框架，而是回答一个更老的问题：**怎么让工程不失败**。

课程关心的核心判断是：当「把一个想法变成能运行的软件」这件事的成本发生数量级坍塌之后，什么能力还值得训练？第 1 讲给出的三层回答是——

- **信息差**：知道计算机世界里有什么、知道哪里能找到答案；
- **能坐牢**：做了决定以后有人要承担后果；
- **能驾驭**：能把人、工具和反馈组织起来，最终做成一件事。

三条之中，课程最关心最后一项。课程以案例和自由讨论为主，课堂完整记录、课后重新整理，以切片形式公开，目标是让讨论**可搜索、可引用、可修订、可重组**。

### 课程 Policy（两条）

1. **Token 自费**：亲自使用才形成成本—质量—延迟意识；但不鼓励 tokenmaxxing。
2. **尽量「通过 / 不通过」**：最终的证据不是分数，而是别人可以打开、运行、质疑并继续使用的**作品**。

> 说明：上面的“能坐牢”为课堂口语表述，第 2 讲已澄清并作补充——责任必须与决策权、情境判断与停止权绑定。

### 各页面说明

- **index.html** —— 站点首页。含课程简介、AI 时代软件工程的意义、讲义列表（支持搜索）与深浅色切换。
  讲义列表通过 **GitHub Contents API 实时读取仓库根目录**自动生成，因此往根目录丢一个新 HTML 就会被自动收录；网络不可用时回退到内置静态清单。
- **讲义页** —— 每一讲的完整笔记：侧栏目录、全文搜索（按 `/` 聚焦搜索框）、附录折叠、术语表、金句、自测清单（勾选状态存 localStorage）、公式与代码块。
  顶部有「← 返回主页」，右下角有回主页悬浮按钮，也可直接按 `Esc`。
- **exercises/ 习题页** —— 每讲配套习题，三部分：**论述题**（作答要点折叠）、**实践题**（任务 → 交付物 → 做完再想）、**解答题**（参考答案折叠）。
  每题下方有「我的作答」输入框，内容自动保存在本机浏览器；支持一键展开/收起、清空、打印。

## 本地预览

仓库是纯静态站点，无需构建。任选一种：

```bash
# 方式一：Python
python -m http.server 8000

# 方式二：Node
npx serve .
```

然后打开 <http://localhost:8000>。直接双击 `index.html` 也能看，但首页的讲义列表依赖 GitHub API，建议用本地服务器打开。

## 维护约定

**新增一讲笔记**：把 HTML 放到仓库根目录，命名遵循

```
NJU-生成式软件工程-第NN讲-标题.html
```

文件名中的「第NN讲」决定排序与角标（建议两位数字，如 `第07讲`）；`index.html` 自身、`404.html` 及含「习题」的文件不会被列入索引。

**新增习题**：放在 `exercises/` 子目录，命名 `NJU-生成式软件工程-第NN讲-习题.html`，入口只写在对应讲义页内（首页的 API 只列根目录，天然不会收录子目录）。

> ⚠️ 注意：**不要用 `.gitignore` 去隐藏需要发布的页面**。GitHub Pages 只提供已提交的文件，一旦被忽略就会变成线上 404。

**发布**：推送到 `main` 分支，GitHub Pages 会自动部署。修改后若浏览器看到的还是旧内容，按 `Ctrl + F5` 强制刷新。

## 技术说明

- 纯 HTML / CSS / 原生 JavaScript，**无框架、无构建、无外部 CDN 依赖**，可离线打开。
- 深浅色主题统一使用 localStorage 键 `gse-theme`；讲义自测清单 `gse1-tasks`；习题作答 `gse1-exercise`。
- 托管方式：GitHub Pages（Settings → Pages → Deploy from a branch → `main` / `/(root)`）。
